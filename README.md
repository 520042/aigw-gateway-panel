# AIGW Gateway Panel · AI 资源整合网关面板

把散落在各处的 AI 网关程序、官方 API 平台、公益中转站统一收进一个本地面板：
**登录、签到、积分、模型倍率、工具调用、智能路由、通知、资源档案**一套搞定。

> 纯 Python 标准库实现，零第三方运行时依赖，单文件即可运行。

## 快速开始

### 环境要求
- Python 3.8+（无第三方依赖，纯标准库）

### 部署运行

```bash
# 克隆项目
git clone https://github.com/520042/aigw-gateway-panel.git
cd aigw-gateway-panel/aigw-panel

# 直接运行
python3 main.py
```

启动后：
- 默认监听 `http://127.0.0.1:8800`
- 浏览器自动打开面板页面
- 数据全部存在 `data/` 目录，纯本地

### 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `AIGW_PANEL_HOST` | `127.0.0.1` | 监听地址（改成 `0.0.0.0` 允许外部访问） |
| `AIGW_PANEL_PORT` | `8800` | 监听端口 |
| `AIGW_NO_BROWSER` | `0` | 是否禁用自动打开浏览器（设为 `1`） |
| `AIGW_GATEWAY_PATH` | - | workbuddy-gateway 二进制路径 |

### 后台运行

```bash
# Linux/macOS 后台运行
nohup python3 main.py > panel.log 2>&1 &

# 或者用 systemd / supervisor 托管
```

## 使用指南

### 第一步：登录接入源
进入「接入源」页面，选择你要接入的平台：

- **扫码登录**（推荐）：点「开始登录」→ 等二维码出现 → 用手机扫码 → 自动登录成功
- **Cookie 登录**：打开浏览器登录平台 → 面板自动提取 Cookie
- **API Key 接入**：手动粘贴平台的 API Key / Refresh Token

### 第二步：配置路由
进入「路由与模型」页面：
- 勾选要加入路由的账号
- 设置权重、优先级
- 点「探延迟」测出各上游实际延迟

### 第三步：客户端接入
在任何 OpenAI 兼容客户端里填：

```
base_url = http://127.0.0.1:8800/v1
api_key  = admin
model    = auto-fast      # 自动选最快的上游
         # auto-weight   # 按权重选
         # auto-priority # 按优先级选
```

### 智能路由策略

| 自动模型 | 策略 | 选路规则 | 适用场景 |
|---------|------|---------|---------|
| `auto-fast` | fastest | 实测延迟最低优先 | 追求响应速度 |
| `auto-weight` | weight | 权重高优先，同权重比延迟 | 主用某家、备用某家 |
| `auto-priority` | priority | 严格按优先级，失败才降级 | 必须走某家 |

### 引擎能力
- **延迟探测**：每 60 秒并发探测，EWMA 平滑
- **熔断**：连续 3 次失败自动摘除，冷却 60s 后恢复
- **自动降级**：429 / 5xx / 超时自动切下一个上游
- **会话亲和**：同一对话尽量固定同一上游，避免上下文抖动
- **能力过滤**：带 tools 自动排除不支持工具调用的；带图片自动排除不支持视觉的

## 技术架构

```
aigw-panel/
├── main.py                 入口：HTTP 服务 + API + 中转端点
├── app/
│   ├── upstreams.py        上游结构化档案
│   ├── router.py           路由引擎：探测/熔断/选路/降级
│   ├── catalog.py          导航展示数据
│   ├── store.py            本地持久化（JSON 原子写）
│   ├── gwlogin.py          登录流程管理
│   ├── qrlogin.py          服务端远程扫码
│   ├── cdp.py              CDP 浏览器 Cookie 提取
│   ├── gwextra.py          平台内部能力（签到/积分等）
│   ├── native_relay.py     原生中继（内置 AI 平台）
│   ├── web_relays.py       网页版逆向中继
│   ├── sitecheck.py        中转站签到/余额引擎
│   ├── notify.py           推送通知
│   ├── scheduler.py        后台调度
│   └── static/             前端页面
└── data/                   运行时数据
```

**技术栈：**
- 后端：Python 3 标准库（http.server / json / threading）
- 前端：原生 HTML / CSS / JavaScript（无框架）
- 协议：OpenAI 兼容 API

## 注意事项

| 项 | 说明 |
|---|---|
| 凭据安全 | 全部只存本机 `data/` 目录，导出的 JSON 含**明文凭据**，别乱发 |
| 公益站风险 | 社区站可能掺水或跑路，勿传隐私数据、勿绑主账号、勿大额充值 |
| 额度有效期 | 多数平台赠送额度有 30/90 天有效期，注意及时使用 |
| 定时精度 | 调度器 20 秒一轮，实际触发在设定时刻之后 0～20 秒内 |
| 公网暴露 | 不要直接把面板暴露到公网，没有内置鉴权防护 |
