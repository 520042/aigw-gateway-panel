========================================
LobsterAI2API 使用说明
========================================

【这是什么】
把有道 LobsterAI（龙虾）的接口，包装成 OpenAI 兼容的本地 API，
方便各类 AI 客户端（Cherry Studio、ChatBot、LobeChat、OpenClaw 等）调用。


【一、运行环境】
- 64 位 Windows（Win7 / Win10 / Win11）
- 无需安装 Go、Node、Python 等任何依赖，单文件绿色运行
- 首次运行会在 exe 同目录自动生成 lobsterai2api-data 文件夹（配置 + 账号）


【二、快速开始】
1. 双击运行 lobsterai2api-gui.exe
2. 会自动弹出浏览器控制台（若没弹，手动打开 http://127.0.0.1:8370）
3. 添加账号（三选一）：
   - 扫码登录：点「开始登录」，用有道账号扫码，最省事
   - 客户端导入：本机装了 LobsterAI 桌面客户端并登录过，一键读取
   - 导入 Cookie：粘贴含 accessToken 的 Cookie（一行一条，支持批量）
4. 回到控制台，点「启动代理」
5. 在客户端里填入下面的地址


【三、客户端配置】
Base URL：http://127.0.0.1:8367/v1
API Key ：sk-lobster-local
模型名  ：任意写法均可（会自动映射），例如
         DeepSeek-V4.1-Flash、deepseek-flash、DeepSeek-V4-Pro、
         glm-5.3、kimi-k2.7-code、qwen3.8-max 等

说明：
- /v1/models 接口不需要 API Key，可直接浏览全部可用模型
- 模型名支持显示名 / ID / 大小写与标点变体，自动匹配


【四、常见问题】
Q：需要自己买额度吗？
A：不需要额外买。用的是你 LobsterAI 账号自带的积分。

Q：关闭浏览器页面后服务会停吗？
A：不会。只要 exe 窗口还在运行，代理就一直在。
   关闭 exe 程序（窗口）才会退出。

Q：能给别人用吗？
A：可以。把本文件夹（去掉了你自己的账号数据）发给对方，
   对方第一次运行后自己登录/导入账号即可。
   注意：每个账号的额度归账号主人，共用会导致额度互相消耗。

Q：端口被占用怎么办？
A：在「高级设置」里改「代理监听地址」，比如改成 :8765，
   保存后重启程序。

Q：账号显示"冷却中"是什么？
A：账号额度用完或触发限流时会自动冷却，到点自动恢复。
   多账号会自动轮换。


【五、高级设置】
在控制台展开「高级设置」可修改：
- 本地 API Key
- 代理监听地址
- 上游 API 地址
- 登录门户地址
修改后点保存，需重启代理生效。


【六、源码】
「源码」目录下是完整的 Go 源码，可自行编译：
    go build -o lobsterai2api-gui.exe ./cmd/gui
需要 Go 1.22 或以上。项目零外部依赖。
