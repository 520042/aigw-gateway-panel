## 一、项目架构

```
                        ┌────────────────────────────────────┐
                        │           aigw-panel (main.py)      │
                        │   ThreadingHTTPServer : 8790+       │
                        └──────────────┬─────────────────────┘
              21 个 /api/* 路由 → dispatch（单接口异常不挂连接）
   ┌──────────┬──────────┬────┴───────┬──────────┬───────────┐
   │          │          │            │          │           │
/api/login  /api/models /api/platform /api/sites /api/route /api/tencent …
   │          │          │            │          │           │
LoginManager  model_extract gwextra    sitecheck  Router    tlogin/tlogin
(gwlogin)   (实时+回退)  (91+17 动作)  (签到站)  (EWMA/熔断) (CodeBuddy原生)
   │          │          │                       │
 账号池     内置清单    upstreams(38 档案)      上游反代
accounts   bundled_*                          GatewayClient→网关 :8317
                                              localproxy→CLIProxyAPI :8318
```

**APP 上下文装配（init_app）**：scheduler（定时签到/成长）· auto_checkin · accounts（账号池
落库 data/accounts.json）· client（GatewayClient）· login_manager · model_rate_cache ·
router（三自动模型路由）· store（JSON 持久化）。

**前端**：纯原生 JS（app/static），无框架；`node --check` 纳入 selftest 第 40 项。

## 三、登录体系（33 平台全通）

| 方式 | 平台数 | 链路 | 验活策略 |
|---|---|---|---|
| 二维码 | 5 | 面板后台线程 → 网关 `/admin/api/login/start{edition}` → QR+授权链接 → 2s 轮询 | copilot `/console/account`（真 200/假 401） |
| Cookie（CDP/手动） | 11 | 打开浏览器登录 → `Network.getAllCookies` 取明文 | 各平台专用端点 + `ok_keys` 业务码 + HTML 判定 |
| localStorage | 1 | 元宝：`LOCAL_AUTH_INFO_KEY_…` 经 storage_keys 补读 | 同上 |
| API Key（**新增**） | 15 | 粘贴 → `GET {base}/models` Bearer 在线验活（200 有效/401 无效） | 真实在校验 |
| 文件 | 1 | Coze PAT 导入 | `/v3/chat/retrieve` bearer |

**不变量（e2e 33/33 验证）**：登录 success 必落库账号池；error 必不落库；secret_of()
完整取回；list() 掩码不泄露；同平台重复登录只更新一条。

## 四、模型获取体系（本次重构核心）

**统一策略（`app/model_extract.py`）**：已登录 → 云端实时拉取；失败 → 内置回退；
响应带 `live` 标志，**界面永不空表**。

| 层 | 来源 | 覆盖 |
|---|---|---|
| ① 实时 API | 各平台 models 动作（gwextra 108 个动作） | codebuddy 系/豆包/元宝/kuku/wps/api-\*15 |
| ② 内置清单 | bundled_doubao(6, 网页版 UI) / bundled_yuanbao(12, dex) / bundled_models(36, APK 倍率表) | 豆包/元宝/codebuddy 未登录 |
| ③ 官方提示 | OFFICIAL.models_hint | api-\* 未配 Key |
| ④ 网关目录 | admin models → /v1/models | 网关型 |

解析器 `extract_generic` 实测兼容：OpenAI `{"data":[...]}`、库库双层
`data.model_list[].model_name/display_name/cost_ratio`、`{models:[...]}` 等 5 种形状。

## 五、倍率识别（三源合并，`_merge_model_rates`）

优先级：**① 网关实测 cost**（只有数字算，「未观测」/0 不算）→ **② 在线目录缓存**
（catalog 拉取，持久化 store）→ **③ 内置表**（36 模型 35 带倍率，四级匹配：
精确→别名→归一化→同族前缀）。每行标 `rate_source` 让用户知道数据出处。

## 七、本次发现并修复的问题（6 个）

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | 15 个官方 API 平台在登录页**没有入口**，用户无法配 Key | gwlogin 只登记了 18 个 APK/网关平台 | `_API_KEY_PLATFORMS` 15 平台注册（file/api_key + Bearer 在线验活） |
| 2 | api-\* 平台模型表恒报错 | platform_models 不认它们 | gwextra 注册 15 个 `/models` 动作 + 未配 Key 回退 hint |
| 3 | wb-gateway 选了平台无模型 | 只认 gwextra 动作 | 新网关型分支：admin models → /v1/models |
| 4 | 库库免登录模型接口被凭据门**挡死**（实测白卡住） | call() 无凭据直接拒绝、不发请求 | 动作级 `no_auth` 标志；kuku 实测免登录拉到 13 个真实模型 |
| 5 | codebuddy 未登录模型表报错 | 无回退 | 回退 APK 内置倍率表 36 模型 |
| 6 | selftest 二维码断言误报 qr=0B | start 是快照，QR 由后台线程 ~2s 后送达 | selftest 轮询等待最多 6s（QR 链路本身实测正常：1226B + authUrl） |

## 八、遗留事项

1. **元宝实时模型结构无样本**：`/api/agent/model/list` 需登录抓包；当前 best-effort
   解析 + dex 内置回退不会报错。拿到样本后应更新 `bundled_yuanbao`（网页版真实名
   为 Hy4 preview/Hy3/DeepSeek 系）。
2. 8 个产品型平台（trae/go/coze/raccoon/metaso/nano/qoder/qwenwork）无公开模型
   API——报错信息已说明原因，属平台限制而非缺陷。
3. api-\* 各控制台 URL（platform.deepseek.com 等）为通用入口，个别平台若改版需核对。
4. selftest 的「网关依赖」检查项需网关进程在线，无网关环境下这些项会 502（环境性，
   非回归）。
