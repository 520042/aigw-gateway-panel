# AI 资源整合网关面板 · aigw-panel

把散落在工作区里的 7 个网关程序（1 个 EXE + 6 个 APK）、22 个官方 API 平台、
12 个 Vibe Coding 反代项目、17 个公益中转站，统一收进一个本地面板：
**登录、签到、积分、模型倍率、工具调用、智能路由、通知、资源档案**一套搞定。

> 纯 Python 标准库实现，PyInstaller 打包成 **单个 EXE**，零第三方运行时依赖。

## 功能一览

| 模块 | 说明 |
|---|---|
| **账号登录** | 18 个平台，扫码 / Cookie(CDP) / 文件 / API Key 四种方式 |
| **定时自动签到** | 13 个 APP 平台，逐平台开关与时间、错峰执行、失败重试、执行历史 |
| **模型与倍率** | APK 内置目录 + 线上目录 + 网关实测三源合并，槽位名↔上游名四级匹配 |
| **工具调用** | 自带 9 个本地执行器，完整跑通 OpenAI `tools` 协议往返 |
| **端点探测** | 解决「整站 401、404 探测法失效」的平台（豆包/千问/Qoder 等） |
| **智能路由** | EWMA + 熔断 + 降级 + 会话亲和 + 工具/视觉能力过滤 |
| **UI** | 亮/暗双主题、侧边栏分组、可搜索排序分页的数据表、响应式 |

## 一、快速开始

```
双击 aigw-panel.exe
```

启动后：
- 浏览器自动打开 `http://127.0.0.1:879x/`（端口自动选空闲位，通常 8790 起）
- **任务栏右下角出现蓝色托盘图标**（找不到图标点一下右下角的 `^` 展开隐藏区）
- 数据全部存在 **exe 同级的 `data/` 目录**，纯本地，不外传

### 托盘图标怎么用

| 操作 | 效果 |
|---|---|
| **双击** | 打开面板 |
| **右键 → 打开面板** | 同上 |
| 右键 → 启动网关 | 手动拉起 workbuddy-gateway |
| 右键 → 停止网关 | 停掉托管的网关进程 |
| 右键 → 开机自启动 ✓/✗ | 开关当前用户 Run 注册表项 |
| **右键 → 退出** | 完全退出（托盘图标消失） |

关浏览器页面 ≠ 关程序，HTTP 服务还在跑，必须从托盘退出。

### 为什么之前看不到图标

`console=False` 的 PyInstaller 程序是 GUI 子系统，**没有主窗口**。
Windows 不给没有窗口的进程分配任务栏位置——这不是 bug，是这类程序的固有行为。
本版本用两个手段解决：

1. **设置 `AppUserModelID`**（`AigwPanel.AIResourceHub`）→ 任务栏正确分组，图标可固定
2. **托盘常驻** → 消息循环持续运行，图标不会因为没有窗口而消失

### 命令行参数

```
aigw-panel.exe            正常启动（自动开浏览器）
aigw-panel.exe --tray     静默启动到托盘，不开浏览器
```

环境变量：

```
AIGW_PANEL_PORT=9000     固定面板端口（默认自动选 8790+）
AIGW_GATEWAY_PATH=...    手动指定网关 exe 路径
AIGW_NO_BROWSER=1        不自动打开浏览器
```

## 二、智能路由（核心）

面板本身就是中转层。客户端只填一个地址 + 一个虚拟模型名，
剩下的路由引擎决定走哪家。

```
base_url = http://127.0.0.1:<面板端口>/v1
api_key  = admin
model    = auto-fast
```

### 三个自动模型

| 自动模型 | 策略 | 选路规则 | 适用 |
|---|---|---|---|
| `auto-fast` | fastest | 实测延迟（EWMA 平滑）最低优先 | 追求响应速度 |
| `auto-weight` | weight | 站点配置的权重高优先，同权重比延迟 | 主用某家、备用某家 |
| `auto-priority` | priority | 严格按优先级数值升序，失败才降级 | 必须走某家，不行再退 |

### 引擎能力

| 机制 | 细节 |
|---|---|
| 延迟探测 | 每 60 秒并发 `GET /models`，EWMA 平滑（α=0.3），新 = 0.7×旧 + 0.3×本次 |
| 熔断 | 连续 3 次失败 → OPEN 摘除，冷却 60s 后自动可再选（懒判断） |
| 自动降级 | 429 / 5xx / 超时自动切下一个，最多试 4 个 |
| 不该降级的 | **4xx（除 429）直接报错** —— 请求本身有问题，换家也没用 |
| 会话亲和 | 请求带 `aigw_session`，同一对话尽量固定同一上游，避免上下文抖动 |
| 能力过滤 | 请求带 `tools` 自动排除不支持工具调用的；带图片自动排除不支持视觉的 |
| model 重写 | 请求里的 `model` 自动替换为该上游真实模型名 |

### 单次请求覆盖策略

```json
{
  "model": "auto-weight",
  "aigw_strategy": "priority",
  "aigw_session": "conv-123",
  "messages": [{"role": "user", "content": "你好"}]
}
```

响应里的 `_route` / `_aigw_route` 会带回路由痕迹，方便确认走了哪家。

### 纳入外部站点

「资源站点」→ 编辑 → 勾「加入路由」→ 填上游模型名、权重、优先级 → 保存。
路由表立刻重建生效。

### 账号登录（面板自己跑完登录，不再让你去敲命令）
这是「集成 7 个 APP 网关」的落点：以前只能让你去命令行跑 `workbuddy-gateway login`
或手工导入文件，现在面板自己把登录流程跑完，凭据落进账号池。

| 平台 | 登录方式 | 面板做什么 |
|---|---|---|
| WorkBuddy 网关 · 国内站 | 二维码 | 调 `/admin/api/login/start{edition:cn}` 取二维码 + 授权链接，轮询 `/login/poll?id=` 到成功 |
| WorkBuddy 网关 · 国际站 | 二维码 | 同上，`edition=intl`（授权页为 workbuddy.ai） |
| Trae / aigw.app | 二维码 | 同一套 copilot 授权，登录后可直连 api.trae.cn |
| CodeBuddy 国际版 | 二维码 | 国际站授权 |
| 豆包 dev.doubao2api | Cookie | 开调试浏览器 → 你登录 → 面板取 Cookie；也支持手动粘贴 |
| 元宝 dev.yuanbao2api | Cookie | 同上 |
| 小浣熊 dev.raccoon2api | Cookie | 同上，另可一键调「登录送积分」 |
| Go 原生网关 | 文件 / Key | 填写凭据（保留，不作为唯一手段） |

- **二维码**：直接内嵌显示（`data:image/png;base64`），旁边有「打开授权页」按钮，
  每 2 秒轮询状态，显示剩余秒数，成功后自动落库
- **Cookie**：Chrome 127+ 把磁盘 Cookie 换成了 app-bound 加密（`v20`），
  普通进程**解不开**。面板改用 **CDP**（Chrome DevTools Protocol）让浏览器
  自己把已解密的 Cookie 交出来；老版本 Chromium 走磁盘直解（`v10/v11`）；
  两条路都不通时降级为手动粘贴
- **密钥安全**：列表接口一律掩码（`sessionid…7890`），完整密钥只在本机调上游时取出

## 六、注意事项

| 项 | 说明 |
|---|---|
| **改前端必查语法** | 浏览器解析失败会**静默拒绝整个 app.js**，页面卡在"正在加载"且控制台无报错。改完先跑 `node --check` |
| 凭据安全 | 全部只存本机 `data/` 目录。导出的 JSON 含**明文凭据**，别乱发 |
| 公益站风险 | 社区站可能掺水或跑路，勿传隐私数据、勿绑主账号、勿大额充值 |
| 额度有效期 | 多数平台赠送额度有 30/90 天有效期，务必开「用完即停」 |
| Turnstile | AnyRouter 等站点的签到开了 Cloudflare Turnstile，脚本过不去，需手动过一次；Cookie 过期后要重取 |
| 定时精度 | 调度器 20 秒一轮，实际触发在设定时刻之后 0～20 秒内 |
| 路由样本 | 延迟优选要接 2 个以上真实上游才有区分度。延迟参考：本地网关 10ms，Groq/Cerebras 极低延迟，公益站通常 200–800ms |

## 六、注意事项

| 项 | 说明 |
|---|---|
| 凭据安全 | 全部只存本机 `data/` 目录。导出的 JSON 含**明文凭据**，别乱发 |
| 公益站风险 | 社区站可能掺水或跑路，勿传隐私数据、勿绑主账号、勿大额充值 |
| 额度有效期 | 多数平台赠送额度有 30/90 天有效期，务必在各平台开「用完即停」 |
| Turnstile | 部分站点签到开了 Cloudflare Turnstile 验证，脚本无法自动过，需手动点一次 |
| WAF 站点 | AnyRouter 等走 Cloudflare，Cookie 会话过期后需重新获取 |
| 定时精度 | 调度器 20 秒一轮，实际触发时间在设定时刻之后 0～20 秒内 |
| 单实例 | 面板本身不做互斥，可用端口环境变量开多份；网关 exe 有 `Local\WorkBuddyGatewayMutex` 互斥 |
