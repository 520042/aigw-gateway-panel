## 续：Kilo Gateway 模型「需要 GitHub 认证」实为模型 ID 截断 bug

### 用户原话意图
截图反馈 Kilo Gateway 模型 `laguna-s-2.1-free@kilo` 请求报错 `Please use an exact model id as listed on /api/gateway/v1/models`，认为是 GitHub 认证问题，要求「看看源码，试试能不能完全破解掉」。

### 结论（先澄清）
Kilo Gateway **不是** GitHub 认证车道。`native_relay.py` 的 `RELAY_SPECS["kilo"]` 是 `auth:"none"` + `secret_fixed:"public"`（免凭据公共池），`gwlogin.py` 也标 `method:"anon"`、`placeholder:"无需填写"`；relay 在 `auth=="none"` 分支 `pop("Authorization")`，**完全不发任何鉴权头**。所谓「认证失败」是面板把模型 ID 的 `org/` 前缀截掉后，上游找不到该 ID 回 404/401 的假象。不做「破解认证」（本就是免凭据），做的是修面板自身的 ID 处理 bug。

### 根因
- `native_relay.py:858` `free_models()`：`base = mid.split("/")[-1]` 把 Kilo 免费池 ID（形如 `poolside/laguna-s-2.1:free`，带 `org/` 前缀 + `:free` 后缀）截成 `laguna-s-2.1:free`；Kilo 上游**要求完整 org/ 全名**才能命中（Zen 联营道才接受裸名）。
- `app/static/app.js:2544` `gmJs()` 正则 `/[^\w.@:-]/g` 把 `/` 替换成 `_`，会让测试/开关/复制按钮把完整 ID 二次破坏成 `poolside_laguna-s-2.1:free`。

### 修复
- `native_relay.py`：`kilo` 规格新增 `models_keep_org: True`；`free_models()` 改为 `base = mid if spec.get("models_keep_org") else mid.split("/")[-1]`，仅 Kilo 保留 `org/` 前缀（Zen 仍走截断）。
- `app/static/app.js`：`gmJs` 正则放宽到 `/[^\w.@:/-]/g`，放行 `/`（`/` 在单引号 JS 串 + 双引号 HTML 属性里是安全字符）。

1. `py_compile` + `node --check` → OK。
2. `free_models("kilo")` 直连上游 → 16 个免费模型，0 个缺失 `org/` 前缀。
3. `relay_once("kilo", {model:"poolside/laguna-s-2.1:free",...}, "public")` → ok=True、真实回复。
4. **build_appdata.py 重构建** → 85 文件干净，base_library.zip 合法；杀旧面板（PID 51504）→ 启动新 EXE。

2. **srcModels key 不一致**：`refreshSrcModels(s.key)` 按卡片 key（合并卡 'copilot'）存，卡片/抽屉却读 `srcModels[vpids[0]]`（'wb-gateway'）→ 拉到的清单永远读不到。
3. **抽屉「已启用」按钮无效**：`toggleModel` 只更新 `.gm-id` 行（模型总表），抽屉行不是 `.gm-id`；且 srcModels 模型无 on 状态 → 点击无视觉反馈。

### 实现
- `main.py` `platform_models` 的 `api-` 分支（api-openrouter 专属）：
  - 无 Key 时：从每日榜 `free_models_feed` 过滤 OpenRouter `:free` 模型，挂到**现有** `api-openrouter` 平台下（标注 `free=True`，附注「面板已集成 OpenRouter，填 Key 后即可用」），去重合并官方 hints。
  - 有 Key 时（live /models）：给 `:free` 结尾模型打 `free=True` 标记。
- 新增模块级辅助：`_openrouter_free_from_feed()`（按 "openrouter" 关键字过滤每日榜）、`_feed_integrated_by_key(m)`（返回面板已集成的平台 pid：api-openrouter / pollinations / None）。
- `api_free_models()`：返回前给每条每日榜模型加 `integrated` 字段（前端据此显示「已集成」徽章、避免呈现成"又一个平台"）。
- `app/static/app.js`：「每日免费模型榜」卡片：OpenRouter/Pollinations 行显示 `已集成·填Key即用` / `已集成·免密钥` 徽章；卡片说明补「已集成 = 面板已内置，不再另建重复入口」。
