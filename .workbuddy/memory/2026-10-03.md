### 踩坑
- **TSD 透明代理注入**：zip 首 16 字节是 `25 54 53 44 2d 48 65 61 64 65 72 2d 23 23 23 25`（`%TSD-Header-###%`），
  和用户记忆里 GitHub 下载被注入是同一个坑。不影响用 exe。
- **AndroidManifest 是二进制 AXML**：自写字符串池解析器（struct 解 chunk type 0x0001，按 UTF8/UTF16 flag 分支读长度前缀）
  才能拿到包名/组件/权限。UTF-8 字符串池长度是「双字节续位」编码，不是普通 varint。
- **bash heredoc 吃正则**：带 `[...]` 字符类的正则放进 `<<'EOF'` 会被 bash 处理导致 `unterminated character set`。
  正确做法：写 `.py` 文件再执行，别在 heredoc 里放复杂正则。
- `re.finditer()` 返回 Match 对象，**没有 `.decode()`**，要用 `.group().decode()`。

### 网关鉴权契约（实测得出，文档没写）
```
1. POST /admin/api/setup      {"username","password"}   首次初始化
2. POST /admin/api/login/key  {"username","password"}   登录（⚠️ 字段是 password 不是 key）
3. 之后所有 /admin/api/* 带 Cookie
   未登录 → {"error":{"code":"login_required"}}
   未初始化 → {"error":{"code":"setup_required"}}
```
`/v1/*` 走 `-api-key` 的 Bearer（默认 admin）。
内置调度：签到 09:00 / 成长 10:00 / 凭据热加载 5s / 用量保留 90 天。

### 技术决策
- **纯标准库**：不用 Flask/FastAPI/requests，保证 PyInstaller 打包干净、EXE 体积小
- **前端零框架零构建**：SVG 手绘 24h 曲线，12 个 `viewXxx()` 渲染函数 + `VIEWS`/`LOADERS` 映射
- 面板自己也是 OpenAI 端点（`/v1/chat/completions` 转发到网关），少一跳

### 踩坑（本次新学）
- **`base_dir()` 算错**：`os.path.abspath(__file__ + "/..")` 是错的，`__file__` 是文件不是目录。
  必须 `os.path.dirname(os.path.abspath(__file__))`。第一版导致 data 目录建到了工作区根。
- **`APP["sched"]` 与 `threading.Thread` 冲突**：Scheduler 继承 Thread，键名改 `APP["scheduler"]`。
- **`safe()` 返回 tuple 忘了解包**：导致 `AttributeError: 'tuple' object has no attribute 'get'`，
  整条路由 500 掉。修法：`safe()` 统一返回 `(body, status)`，另加 `safe_dict()` 只要 body。
- **成功判断不能用 body 里有无 `ok` 字段**：网关的 `/admin/api/usage` 成功时返回裸数据没有 `ok`，
  用 `u.get("ok")` 判失败会误报 502。改用 HTTP 状态码判断。
- **PyInstaller 静态资源路径**：源码 `HERE=项目根`，静态在 `HERE/app/static`；打包后 `_MEIPASS/app/static`。
  写候选列表逐个探测。
- **EXE 在 dist/ 找不到网关**：写「从 exe 目录向上 5 层逐个探测 + 环境变量 + 浅层 walk 兜底」三级搜索。
- **调度器启动即补跑当天签到**：加 45 秒静默观察期，等用户先看到面板。
- **单接口异常打挂连接**：加统一 `dispatch()` 兜底，任何异常转成结构化 JSON，不影响其他接口。
